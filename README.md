# Piyumi MPhil Thesis Workspace

This workspace is organized to finalize an MPhil thesis through a Markdown-first workflow.

The current project focus is the development of enhanced reflective coatings for CsI(Tl) scintillation detectors, with an integrated personal radiation monitoring network as an application phase.

Start with `AGENTS.md`, then use the Markdown drafts in `chapters/`.

## Folder Map

- `chapters/` - editable Markdown thesis drafts.
- `source_documents/` - preserved Word/PDF source material.
- `figures/` - original, generated, and processed figure assets.
- `references/` - citation library, reference notes, and bibliography files.
- `project_docs/` - workflow, formatting, citation, review, and figure instructions.
- `logs/` - work log and decision record.
- `output/` - generated Word/PDF/submission files.
- `tools/` - future helper scripts for export, validation, and formatting.
