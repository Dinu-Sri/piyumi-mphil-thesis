# References And Citations

## Rules

- Do not fabricate citations.
- If a source is missing, add `<!-- TODO: citation needed -->`.
- If a result is from the candidate's experiment, identify the source chapter, table, figure, or data file.
- Keep citation style consistent across chapters.
- Prefer a single managed bibliography file when the citation library is available.

## Planned Reference Assets

Place future citation files here:

- `references/citation_database/thesis_references.bib`
- `references/library/` for PDFs or source papers.
- `references/notes/` for source summaries and extraction notes.

## Citation Review Checklist

- Every factual literature claim has a citation.
- Every method adapted from literature has a citation.
- Instrument models and datasheet claims have citations.
- Numerical results from the thesis are traceable to a table, figure, or data file.
- References cited in text appear in the final reference list.
- Reference list entries are complete enough for examination.
