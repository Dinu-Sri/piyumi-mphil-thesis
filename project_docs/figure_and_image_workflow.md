# Figure And Image Workflow

## Folder Rules

- Original images: `figures/source_images/`.
- Processed or cleaned images: `figures/processed/`.
- AI-generated or designed visuals: `figures/generated/`.

Never overwrite source images. Create a derived copy instead.

## Figure Development

For each thesis figure, maintain:

- Source image or data.
- Edited/generated asset.
- Caption draft.
- In-text callout.
- Notes on what the figure proves.

## Scientific Figure Standards

- Figures must support a specific claim in the text.
- Captions should state what is shown, key conditions, and why it matters.
- Avoid decorative scientific images in thesis chapters.
- Label materials, binders, concentrations, instruments, and conditions where relevant.
- Check legibility after Word export.

## Image Generation Rules

Generated images may be used for conceptual diagrams, workflows, or schematic illustrations. Do not use generated images as evidence for experimental results.

When generating an image, save the prompt and intended use in `figures/generated/README.md` or a nearby notes file.
