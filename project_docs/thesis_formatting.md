# Thesis Formatting Notes

Primary source: `source_documents/admin_guidelines_and_forms/New-WUSL-Thesis-PreprationGuidelines-Mphil_PhD.pdf`.

## Required Front Matter To Confirm

- Title page.
- Declaration page.
- Supervisor certificate.
- Acknowledgements.
- Abstract, maximum 600 words.
- Table of contents.
- List of tables.
- List of figures.
- List of abbreviations.

## Chapter Body

Expected thesis body:

1. Introduction.
2. Literature Review / Radiation Detection and Monitoring Systems.
3. Materials, Characterization and System Prototyping Techniques / Methodology.
4. Development of Enhanced Coating for a Scintillation Detector.
5. Development of Personal Radiation Monitoring Network.
6. Conclusions, Recommendations and Future Suggestions.

## Formatting Checks Before Word Delivery

- Margins match WUSL guidelines.
- Page numbering is correct for front matter and main body.
- Chapter titles and headings are consistent.
- Figure captions and table captions are numbered correctly.
- Every figure and table is referenced in text.
- References are complete and consistently formatted.
- No placeholder comments remain in final exported files.
